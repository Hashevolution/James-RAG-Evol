## 3. Inverse-lift hypothesis FALSIFIED at mixtral

The Phase B Option A → Phase C llama transition appeared to confirm
an inverse-lift pattern (JAMES Δ inversely proportional to raw
baseline). After fitting on gemma4 + llama + gemma3:12b data,
predictions for mixtral were:

- **noise**: raw 0.68 → Δ ≈ +0.12 → actual +0.080 (within range ✅)
- **negrej**: raw 0.148 → Δ ≈ +0.05~+0.13 → actual **+0.239 ❌**

The negrej prediction was outside the predicted range by 2×. The
single-variable inverse-lift model is insufficient.

### User catches that drove the falsification

1. **Post-hoc fit framed as prediction** (memory entry update): the
   "6/6 prediction hits" table was retroactive curve fitting after
   3 models were measured. Real ex-ante predictions = mixtral
   results only. `feedback_finding_size_honest_framing` directly
   triggered.

2. **0.000 negrej skepticism**: user questioned whether gemma4:e4b's
   0/25 abstention was a measurement artifact (truncation? prompt
   constraint?). Audit confirmed:
   - No truncation (answers 33–444c, max_tokens=8192 untouched)
   - Prompt explicitly requested "Insufficient Information" on
     insufficient context
   - 0 abstention pattern matches in any of the 25 raw answers
   - Cross-model abstention on same prompt (llama 6/25, gemma3:12b
     2/25) confirmed prompt is NOT the issue
   - gemma4:e4b produces "sophisticated hallucination" — quotes
     context ("The context mentions...") then answers confidently
     with distractor-implied content
   - **0.000 is real**, not artifact.

3. **Family vs size separation**: 12b raw negrej 0.148 = mxtral
   raw negrej 0.148 identical. This pointed to family/training
   determining native abstention, not size. Mixtral being 47B
   doesn't help — its native instruction-following remains gemma-
   family-like.

## 4. "True signal" mechanism

Per-model JAMES abstention sets on the 25 negrej queries:

```
gemma4:e4b   JAMES: {3, 9, 15, 18}              4 abstentions
gemma3:12b   JAMES: {14, 15, 17}                3 abstentions
mixtral      JAMES: {3, 9, 14, 15, 17, 18}      6 abstentions
llama        JAMES: {3, 9, 14, 15, 17, 18}      6 abstentions  ← IDENTICAL
```

**mixtral ≡ llama JAMES sets exactly**, despite:
- Different architectures (47B MoE vs 8B dense)
- Different model families (Mistral vs Meta)
- Different training regimes

This **isolates the JAMES pipeline's contribution from model variance**.
The 6-query set {3, 9, 14, 15, 17, 18} is a candidate **"true
signal"** — JAMES's pipeline-emitted abstention triggers, independent
of the downstream model.

### Absorption fraction by model

| 모델 | absorbed | fraction | raw set vs JAMES set |
|---|---|---|---|
| gemma4:e4b | 4/6 | 67% | raw {} → JAMES {3, 9, 15, 18}, pure addition |
| gemma3:12b | 3/6 | 50% | raw {9, 15} → JAMES {14, 15, 17}, lost {9} + gained {14, 17} |
| mixtral | 6/6 | 100% | raw {9, 15} → JAMES {3, 9, 14, 15, 17, 18}, strict addition |
| llama | 6/6 | 100% | raw {7, 9, 14, 15, 18, 20} → JAMES {3, 9, 14, 15, 17, 18}, lost {7, 20} + gained {3, 17} |

The "absorbed fraction" approximates model capacity / instruction-
following: mixtral and llama (high capacity) fully absorb the
signal; gemma family (lower capacity) absorbs partial slices.

### Restated framing

**"JAMES pipeline emits a benchmark-level latent abstention signal.
Model absorption fraction depends on capacity / instruction-
following. Override of base model's native signal is a side effect
of signal-model conflict resolution (visible in gemma3:12b losing
{9} and llama losing {7, 20})."**

This is the **architecturally-invariant claim** the Phase B Option A
inverse-lift framing pointed at but didn't capture.

## 8. What the next session should do

### Recommended order

1. **Phase B Option B cross-bench** (highest leverage for ⭐⭐⭐
   elevation). The "true signal" framing predicts that on ALCE /
   MuSiQue / 2Wiki, the JAMES abstention set is benchmark-specific
   but architecture-invariant per benchmark. Cross-bench validation
   would lift this finding to ⭐⭐⭐ universal-law candidate
   territory. Operator step: download ALCE / MuSiQue / 2Wiki
   fixtures per handover §4.

2. **Prior art literature search** (~1-2h, can run before Option B).
   Identify which framings already exist (boosting, distillation,
   tool-use). Pin JAMES-specific contribution.

3. **Mechanistic ablation** of JAMES verifier (~1-2 PR). Which
   component emits the "true signal"? query_rewrite? orchestrated
   retrieval? reranker? verifier itself? Ablating one-at-a-time
   on RGB-en would isolate the source. ⭐⭐ → ⭐⭐⭐ helper.

### What this session showed about session length

This session ran ~6h on cycle γ Phase B+C measurement (4 raw
baselines + 6 JAMES runs + 2 workspace builds + analysis). The
"big finding" (true-signal mechanism) only emerged at the 4th
model (mxtral negrej, the LAST measurement). Earlier stop would
have shipped the inverse-lift framing as ⭐⭐ confirmed without the
falsification → restatement that strengthened the claim.

**Lesson**: cross-model measurements should run to N≥4 before
claim-finalization. n=3 is enough for hypothesis generation but
insufficient for falsification.
