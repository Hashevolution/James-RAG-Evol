## 10. Why this gap formed

Three observations, recorded so the same pattern can be avoided next
cycle:

1. **Entry path narrowness.** The 2026-05-22 session entered from a
   live-verification checklist (`v0.3.x-session-2026-05-21-review-
   checklist.md §13`) that did not list Plugin API as a track. The
   checklist was an accurate live-verification entry but an
   incomplete cycle entry; future cycles should cross-reference
   `ROADMAP.md` against the checklist before starting.
2. **Discovery work crowded out planned work.** The §3 cognitive
   lang-toggle Phase 1 finding (single PR → systemic i18n debt) was
   real and necessary, but absorbed the cycle. The 7-PR sweep was
   the right call; what should also have happened is a deliberate
   re-plan at the point of discovery.
3. **No mid-cycle status check against `ROADMAP.md`.** A 10-minute
   read of v0.3 deliverables mid-cycle would have surfaced the
   Plugin API gap before the session closed. Adding this as a
   recurring step (e.g., at the start of every session that follows
   discovery work) is the lightest-weight prevention.
