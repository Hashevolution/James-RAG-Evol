## 0. 왜 이 트랙인가 (진단)

- **증상**: "뭘 만드는지 모르겠다 / 덕지덕지 / 좋아지는지 모르겠다."
- **진단**: 열린 피드백 루프. **비용은 엄밀히 측정(V3'), 품질은 가정.**
  라우팅 기계(D1/D5/LEO)는 전부 **flag-OFF 휴면** — 기본 제품은 아직
  v0.3.0 gemma4:e4b 단순 경로. 즉 *품질을 깎는 게 아니라, 켜도 될지
  증명 안 된 휴면 복잡도.*
- **원칙 3개**:
  1. **검증 = 설계** (검증이 설계 *다음*이 아니라 *곧* 설계).
  2. 측정된 셀 = 라우터 규칙 하나. **안 측정 = 규칙 없음 = 안전 fallback.**
  3. 불안은 결함이 아니라 *열린 루프를 읽은 정확한 경고등.* 해법은
     "그만 짓기"가 아니라 "루프 닫기."

## 2. 단 하나의 공백

**비용 축은 cross-validated까지 됐는데(Robin 26b), 품질 축은 측정
기구가 없음.** grounded=20/20 · RAGAS=1.000 전부 포화(회귀 바닥일 뿐
헤드룸 0), answer_relevancy는 노이즈 밴드. → **"품질이 좋아지나"는 현재
레포로 구조적 무응답.** 4번 의심(레이어가 품질을 떨어뜨리나) =
라우팅 제국 전체의 *검증 안 된 주춧돌.*

부수 공백:
- 레이어 ablation은 어떤 계획에도 없음.
- 3×3은 직교(모델×temp at 고정 파이프라인) + 미실행.
- "설계만 하고 안 돌린" 패턴 반복(3×3 미실행, `swap_eval_report.py`
  부재, `bench_lc_scope_arms.py` deferred).

## 3. 품질의 정의 (북극성)

**groundedness + 답 정확도 + 기권 정확도.** 단 — *순수 품질 최대화는
수축을 안 함*(레이어 추가는 품질에 +/중립). 칼날은 **한계
기여(marginal)**: "이 레이어 *있을 때 vs 없을 때* 품질 델타." 0이면 비용
무관 삭제.

## 4. valid ablation 불변식

- **고정**: 모델 + 샘플링 결정성(temp=0 / seed) + judge(다른·강한 모델)
  + 코퍼스 / 쿼리·gold / 생성조건.
- **기법**: paired per-query (쿼리간 분산 상쇄), arm별 반복 — 효과가
  런 흔들림보다 작으면 0.
- **산출물**: **값 매트릭스 (레이어 × 모델 tier).** 0-델타 = 삭제 /
  한쪽 tier만 = **tier-gate(라우터가 레이어까지 라우팅)**. *이 표 =
  라우터 정책표.*

## 5. 스코프 경계

- **지식 풀(gemma)** = 이 트랙 대상. **코딩 풀(qwen/deepseek, Phase 6
  기존)** = *별도 축, 별도 오라클(테스트 통과율)* — 안 섞음.
- **로컬 현실**: 등록된 건 small=gemma4:e4b(로컬) + large=Claude(클라우드)
  뿐, medium 비었음 → *순수 로컬에선 라우터 거의 no-op* (검증할 가설).
  코딩 32b도 12GB 초과로 gemma fallback.
- **B 채택**: `gemma3:12b` 로컬 medium 등록(12GB 적합, Direction 3의 첫
  셀, plugin으로 — core 미오염).
- **하드웨어 = 제약(필터), 품질 = 목적함수.** 박스에 드는 모델로 후보
  거른 뒤 그 안에서 품질로 선택.

## 6. 타이밍 (β 결정 — "품질 검증"을 둘로 쪼갬)

| 조각 | 위치 | 근거 |
|---|---|---|
| **품질 오라클** (비포화 지표 + 고정 baseline) | **Sprint 1** (늦어도 Sprint 4 전) | Sprint 4(임베딩 swap, 기본경로 변경)·Sprint 5(Layer 4 게이트)가 *몰래 의존* |
| **검증 = PR 게이트** (규칙2에 이빨) | **Sprint 3~5 상시** | 별도 트랙 아닌 ambient |
| **레이어 ablation + 수축 + flag-ON 결정** | **v0.4 끝 / v0.5-prep** | 휴면이라 무급 · v0.5 Domain Pilot = 처음 ON 출시 시점 |

핵심 사실: D1/D5/LEO 라우팅 기계는 전부 default OFF → 기본 제품은
지금도 byte-identical. 불이 안 났으니 큰 수축은 급하지 않음. 단,
**Sprint 4 임베딩 swap은 flag-gated가 아니라 기본 경로를 바꾸므로**
(합격 기준이 포화된 grounded rate) 오라클 없이는 자기 효과를 증명 못 함
→ 오라클은 capstone이 아니라 prerequisite.

## 8. 미해결 쟁점

- **α (다음 액션, 제일 어려움)**: 비포화 품질 지표를 *뭐로*? — 어려운
  쿼리셋(현 시스템이 못 푸는) or gold 대비 graded 정확도. 레포에 비포화
  지표가 *전무*.

  프로토콜(사전 notice / first-share) 걸림.
- **δ**: 규칙 2 벤치게이트가 지금 포화/비용뿐 — *이 트랙이 규칙 2에
  이빨을 주는 일* (닭-달걀).

- **rule 1** (no domain): ✅ 모두 플랫폼 인프라 / 측정. 도메인 팩 없음.
- **rule 2** (bench numbers): 이 트랙이 규칙 2에 *이빨을 주는* 일 —

- **rule 4** (architecture): 라우터 정책표 / 오라클 일부 `architecture`

- **rule 5** (module ≤ 20 KB): 신규 모듈(오라클 harness, medium backend
  plugin) < 20 KB. 초과 시 분리.
