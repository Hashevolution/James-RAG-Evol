## 3. 변형별 mechanism 분석

### Variant 3: CoT prompt regression (−0.15 EM!)

CoT promptが 12B 모델에 도움 안 되는 mechanism:

| Query | Gold | CoT prediction | 평가 |
|---|---|---|---|
| Who is spouse of Green performer? | Miquette Giraudy | "Insufficient Information." | Abstention (CoT가 multi-hop를 못 풀고 abstain) |
| Who founded distributor of UHF? | Mike Medavoy | "Koch Entertainment" | Wrong entity (회사 이름 대신 정답) |
| Owner of Ciudad Deportiva? | Tamaulipas | "Mexico" | **Less specific** (state 대신 country) |

**해석**: CoT가 모델을 더 generic 한 답으로 유도 — exact match 자리를
잡지 못함. 12B 모델은 CoT 효과 없이도 충분히 reasoning 함; CoT가 추가
noise가 됨. (Cycle γ Phase C.2 → "wall = unsupervised supporting
selection" 정합 — reasoning 자체 잘 함, retrieval / extraction 이
bottleneck.)

### Variant 4: k=10 regression (−0.05 EM)

| Cell | Support recall | EM |
|---|---|---|
| k=5 | 0.65 | 0.15 |
| k=10 | **0.675 (+0.025)** | **0.10 (−0.05)** |

★ Paradox: support_recall **올라감** but EM **떨어짐**. Mechanism:
중간 rank 의 distractor paragraphs (rank 6-10) 가 supporting docs
보다 LLM 의 주의를 더 끌어서 wrong answer 생성. **support_recall =
EM monotonic 아님 confirmed**.

### Variant 2: LLM rerank modest lift (F1 + SR only)

| Cell | EM | F1 | SR |
|---|---|---|---|
| k=5 token | 0.15 | 0.246 | 0.65 |
| k=5 LLM rerank | 0.15 | **0.282 (+0.036)** | **0.725 (+0.075)** |

LLM rerank이 token-overlap top-20 중에서 더 좋은 top-5 선택 (SR +0.075)
→ partial match F1 lift (+0.036) → 하지만 exact match (EM) 변화 없음.
LLM rerank이 supporting docs 잘 골라도, 답변 정확도까지 끌어올리지
는 못함 (reasoning quality bottleneck 별도 axis).
