#### Cell #2: S1 × james × gemma3:12b (12B param, Google Gemma family)

| Axis | token | LLM-grounded | Δ (LLM − token) |

Elapsed: 833s (180 queries × 4.6s/query). Marginal lift: 12B 모델이
top-10 내 reorder만 (R@10 unchanged), 단 top-1 정확도 +2.2pp.

#### Cells #3-5: **S2 × 3 SUT × gemma3:12b** ★★★ key leg

| SUT | R@1 token | **R@1 12B LLM** | Δ R@1 | R@10 token | R@10 12B LLM | temporal_acc 12B LLM |
|---|---|---|---|---|---|---|
| **Vanilla** | 0.225 | **0.400** | **+0.175** | 0.950 | 0.9375 | 0.9375 |
| **Naive-supersede** | 0.5375 | **0.6125** | **+0.075** | 0.7500 | 0.7625 | 0.7625 |
| **JAMES** | 0.7125 | **0.7750** | **+0.0625** | 0.9750 | 0.9625 | 0.9625 |

Elapsed: 370s per SUT × 3 = 1110s total (80 queries × 4.6s/query).

★★ **Cross-cell findings**:

1. **S2 rank-order V < N < J on R@1 PRESERVED under LLM rerank**:
   token: 0.225 < 0.5375 < 0.7125
   gemma3:12b: 0.400 < 0.6125 < 0.7750
   → ⭐⭐⭐ ladder leg 1 cleared (1 of 4 model)
2. **All 3 SUT benefit from rerank on R@1** (Vanilla +0.175 가장 크고,
   강한 SUT 일수록 marginal gain 작음 = literature 정합)
3. **JAMES still wins** but gap narrows: token V-J gap = 0.4875,
   12B LLM V-J gap = 0.375
4. **R@10 / temporal_acc 는 약간 떨어짐** (~-0.0125) — top-10 안에
   reorder만 발생 + 일부 borderline 정답 displaced. R@1 lift 가
   top-10 안 redistribution 의 trade-off.

★ Publishable framing: **JAMES validity-window mechanism 이 LLM
rerank 와 orthogonal하게 작동** (rank-order 보존). LLM rerank 는
"weak SUT (Vanilla) 를 끌어올리지만 JAMES advantage 자체는 보존".
즉, **operational moat (validity-window) + retrieval-quality boost
(LLM rerank) 가 additive** — 둘 다 채택 가능, 둘 중 하나만으로 충분
하지 않음.

### 2.3 Capability emergence ladder

| Model | Size | S1 james R@1 | Δ from token |
|---|---|---|---|
| (token baseline) | — | 0.7389 | — |
| gemma4:e4b | 4B | 0.7056 | **−0.0333** (regression) |
| gemma3:12b | 12B | **0.7611** | **+0.0222** (lift) |
| mixtral:8x7b | 47B (8×7B MoE) | pending | — |
| claude-haiku-4-5 | cloud | pending (operator action) | — |

★ Clean **size threshold finding**: capability emerges between 4B and
12B for LRB rerank task. 4B 미만 = regression risk, 12B+ = positive
contribution. literature 정합 (Schapire 1990 boosting + RAG
"cheat-sheet effect" 패턴 mirror — cycle γ prior art 정합).

★★ Hypothesis 검증 위해 mxtral (47B) 측정 필수 — 47B가 12B보다 더
큰 lift 시 monotonic scaling, 약한 lift / regression 시 plateau /
inverse scaling.
