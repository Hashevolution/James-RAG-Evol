# 3-Line Summary

## English

- **What it is**: A 100% locally-runnable, security-first Graph-RAG knowledge engine with an explicit ontology (12 relation types) and a self-evolution scaffold.
- **Who it's for**: Researchers and engineers who need explainable retrieval with built-in access control on a single machine.
- **Status**: v0.1.0-alpha — working prototype validated on synthetic + adversarial data (83-item security suite, 65-item diagnostic). MIT-licensed. Real-data testing is the v0.2 focus, feedback welcome.

## 한국어

- **무엇**: 100% 로컬에서 도는 Graph-RAG 지식 엔진. 12종 온톨로지 관계, 자가진화 스캐폴드, 3계층 보안 모델을 한 코드베이스에 묶었습니다.
- **누구를 위해**: 한 대 노트북에서 "설명 가능한 검색 + 접근 제어"가 동시에 필요한 연구자·엔지니어.
- **현재**: v0.1.0-alpha — 합성/적대적 데이터 83항목 보안 테스트, 65항목 진단 통과. MIT. 실데이터 검증은 v0.2 목표, 피드백 환영.
