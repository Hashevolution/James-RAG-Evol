        ▸ LLM Routing
      

      

        

          모델 / 자동설정 / 라우팅 토글이 한 자리에 모인 통합 설정입니다.
          DB 값이 우선이고, DB 가 비어 있으면 환경 변수 → 기본값 순으로
          적용됩니다. 우측 "env 로 되돌리기" 버튼은 DB 행을 지워 환경
          변수가 다시 작동하게 합니다.
        

        
        

          ⚠️ 이 설정은 모든 워크스페이스가 공유합니다 (workspace-aware
          아님). dogfood / main / cycle-γ 워크스페이스 전환해도 같은 값 적용.
        

        
        

          측정 실행 시 (qvt_ablation_matrix / RAGAS / cycle-γ 등) 는
          JAMES_SETTINGS_USE_DB=0 으로 env 가 source-of-truth 가 되도록
          하세요. 그렇지 않으면 여기서 설정한 DB 값이 측정 결과에 silent 하게 반영됩니다.

        에이전트 챗
      


      
      

        

          자연어로 지시하면 LLM 이 도구 (list / read / write / edit / glob /
          grep) 호출을 결정합니다. 에이전트는 에이전트 폴더
          페이지에서 등록한 폴더 안에서만 작업할 수 있습니다.
        

        

          모든 호출은 audit log 에 기록됩니다. admin role 만 사용 가능합니다.
        

        
        

          ⚠ 셸 명령 실행(run_shell)은 기본 비활성입니다 —
          JAMES_AGENT_ENABLE_SHELL=1 설정 시에만 작동합니다.
